## Исследуемая модель

Время разделено на слоты, длительность которых равна времени передачи одного сообщения. В каждом слоте возможны успешная передача одного абонента, конфликт нескольких передач или отсутствие передачи.

Интенсивность входного потока обозначена через $\lambda$. Поступление новых сообщений моделируется распределением Пуассона, а попытки передачи активных абонентов — биномиальным распределением.

## Основные результаты

### Лабораторная работа № 1

При приближении интенсивности потока к критическому значению $\lambda = e^{-1} \approx 0{,}368$ система достигает предельной пропускной способности. После перехода через эту границу очередь активных абонентов и время ожидания быстро растут.

## Общий вывод

Обе лабораторные работы показывают переход системы из устойчивого режима в режим перегрузки вблизи $\lambda = e^{-1}$. До критической точки входной поток обслуживается без значительного накопления очереди. После неё число ожидающих абонентов и задержка резко увеличиваются, тогда как пропускная способность остаётся вблизи предельного значения.
